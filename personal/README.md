# Personal editions

Full-featured copies of every plugin in this pack.

These editions may reach into Hermes Desktop internals (app DOM, persisted app keys, raw bridge calls). They are **not** the catalog-listed builds. Install only if you accept that risk: a Hermes Desktop update can break them, and they are outside the plugin SDK contract.

This is the edition I run locally.

```bash
hermes plugins install apoapostolov/hermes-agent-awesome-plugins/personal/<id>
```

Replace `<id>` with the plugin folder name (`provider-status`, `sidebar-manager`, …).

Listed, SDK-only builds live in [`../public`](../public).
